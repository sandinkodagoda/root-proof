# RootProof Assets

Place editable assets in these folders before hosting.

- `logo/` - add the final RootProof logo image, for example `rootproof-logo.png`.
- `images/` - add website screenshots, hero images, or product visuals.
- `social/` - add LinkedIn, Facebook, and YouTube post visuals used for the assignment.
- `qr/` - add the QR code that links to the hosted website after your friend publishes it.

The current website uses a text-based RootProof logo so the pages work even before the final logo image is added.
