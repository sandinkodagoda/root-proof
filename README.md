# RootProof Static Website Mock-up

This is an editable static website mock-up for the RootProof digital marketing assignment.

## Pages

- `index.html` - homepage
- `products.html` - RootProof Lifecycle, Product Hub, and Passport
- `industries.html` - rubber industry focus and future expansion
- `resources.html` - education hub for EUDR, DPP, and product proof content
- `about.html` - brand purpose and academic simulation note
- `book-demo.html` - simulated demo enquiry page

## Editing

Open any `.html` file in a browser to preview it. Edit page content directly in the HTML files. The visual styling is in `css/style.css`, and the small mobile menu/form behaviour is in `js/main.js`.

## Logo

The site currently uses a text-based RootProof logo. Add the final logo image to `assets/logo/` and update the header if you want to use the image logo instead.

## Hosting

The folder can be hosted as a static website on Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any standard web hosting service.

## Academic Note

The footer states that this website is created as part of an academic digital marketing strategy simulation.
